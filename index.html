Промт-академия

Изучите структуру эффективных запросов, шаблоны и техники для разных моделей.

Формула CRISPE

Контекст + Роль + Инструкция + Стиль + Параметры + Примеры

Контекст: пишу пост для Telegram-канала о ИИ Роль: ты — эксперт по контент-маркетингу Инструкция: напиши 3 варианта заголовка Стиль: разговорный, с иронией Параметры: до 80 символов каждый Пример: "ChatGPT украл мою работу — и я благодарен"

Chain-of-Thought

Заставьте модель «думать» шаг за шагом. Добавьте «Давай разберём пошагово» или «Объясни ход мыслей».

Реши задачу пошагово: 1. Определи известные переменные 2. Выбери формулу 3. Подставь значения 4. Проверь результат

Zero-shot vs Few-shot

Zero-shot — без примеров, полагаясь на знания модели.
Few-shot — 2-5 примеров ввода-вывода для точности.

Negative Prompting

Для изображений: указывайте, чего не должно быть. Для текста: «Не используй канцеляризмы», «Избегай повторов».

🔍 Живые примеры с разбором (10 тематик)

Каждый пример показывает разную структуру промта. Скопируйте и адаптируйте под свою задачу.

🛒 E-commerce: описание товара для маркетплейса

CRISPE 
[Контекст] Продаём беспроводные наушники на Ozon, целевая аудитория — студенты 18–25 лет.
[Роль] Ты — копирайтер маркетплейса с опытом в электронике.
[Инструкция] Напиши описание товара из 5 блоков: заголовок (до 60 симв), 3 буллита преимуществ, SEO-описание (500 симв), 5 характеристик, CTA.
[Стиль] Энергичный, с эмодзи, без воды.
[Параметры] Ключевые слова: TWS, Bluetooth 5.3, шумоподавление.
Разбор: Контекст задаёт ЦА, роль — экспертизу, инструкция дробит задачу на блоки (модель не упустит часть), параметры — SEO-якоря.

💻 Код: рефакторинг + документирование legacy

Chain-of-Thought + Role 
[Роль] Ты — senior Python-разработчик, ментор juniorов.
[Контекст] Унаследовал скрипт на 200 строк, который парсит CSV. Код работает, но не читается.
[Инструкция] 
1. Проанализируй код и найди 3 главные проблемы читаемости.
2. Отрефактори с использованием pandas и pathlib.
3. Добавь docstrings и type hints.
4. Напиши 3 unit-теста на pytest.
[Стиль] Подробные комментарии, объясняй каждое изменение.
Разбор: Chain-of-Thought («1. Проанализируй… 2. Отрефактори…») заставляет модель думать последовательно, а не выдавать результат в лоб. Роль senior даёт качество кода на уровне production.

🤝 HR: вопросы для собеседования на вакансию

Few-shot 
[Роль] Ты — HR-директор IT-компании.
[Задача] Составь 10 вопросов для собеседования на позицию AI-артист (Midjourney/SD).
[Формат Few-shot]
Пример хорошего вопроса: «Покажите портфолио и расскажите, какой промт вы использовали для этой работы и почему?»
Пример плохого вопроса: «Вы умеете рисовать?»
[Требования] 5 вопросов — на hard skills (техника промтов, постобработка), 5 — на soft skills (коммуникация с заказчиком, дедлайны).
Разбор: Few-shot (примеры хорошего/плохого) калибрует модель на нужную глубину. Без примеров ИИ дал бы общие вопросы из Google.

📧 Email-маркетинг: welcome-цепочка

CRISPE + Персона 
[Контекст] Пользователь скачал бесплатный гайд по промтам с лендинга. Нужна цепочка из 3 писем.
[Роль] Ты — email-маркетолог с конверсией в ниши инфопродуктов 15%+.
[Инструкция] 
Письмо 1 (сразу): благодарность + ссылка на гайд + 1 ценный совет (без продажи).
Письмо 2 (через 2 дня): кейс клиента, который заработал первые $100 на промтах + мягкий CTA на платный курс.
Письмо 3 (через 4 дня): FAQ + ограниченное по времени предложение (скидка 20% до пятницы).
[Стиль] Дружелюбный, как письмо от старшего друга. Короткие абзацы, смайлы умеренно.
[Параметры] Тема письма — до 50 символов. CTA-кнопка — яркая, 1 на письмо.
Разбор: Структура писем по номерам — это инструкция с контрольными точками. Модель не смешает цели писем в кашу.

🎨 Арт: концепт-арт персонажа для игры

Negative Prompt + Параметры 
[Промт] Concept art of a cyberpunk female hacker, age 22, asymmetrical undercut with neon-blue hair strands, wearing a holographic bomber jacket, sitting in a cluttered apartment with 3 monitors, warm/cold contrast lighting, cinematic composition, rule of thirds, highly detailed, 8k, artstation trending, unreal engine 5 render style
[Negative Prompt] blurry, lowres, bad anatomy, extra fingers, mutated hands, poorly drawn face, watermark, signature, text, logo, cropped, worst quality, jpeg artifacts, duplicate, ugly
Разбор: Для изображений критичны: точное описание внешности (асимметричный андеркат), освещение (warm/cold contrast), композиция (rule of thirds) и обширный negative prompt — без него модель генерирует артефакты.

📊 Аналитика: суммаризация отчёта для руководителя

Chain-of-Thought + Формат вывода 
[Роль] Ты — стратегический аналитик, готовящий выжимку для СОО.
[Контекст] Ниже отчёт отдела маркетинга за квартал (вставьте текст отчёта).
[Инструкция] 
1. Прочитай отчёт и выдели 3 ключевых достижения.
2. Найди 2 проблемных зоны с указанием метрик.
3. Сформулируй 3 рекомендации с приоритетом High/Medium/Low.
4. Дай прогноз на следующий квартал в 2 предложения.
[Формат] Итоговый документ — не более 1 страницы A4. Используй маркированные списки, без воды.
Разбор: Формат «1. Достигнуто… 2. Проблемы… 3. Рекомендации…» превращает LLM в структурированный аналитический инструмент, а не генератор текста.

🌐 Копирайтинг: структура лендинга для SaaS (AIDA)

Инструкция + Параметры 
[Роль] Ты — копирайтер с специализацией на SaaS-продуктах.
[Контекст] Продаём AI-сервис для генерации видео-контента. ЦА: маркетологи, SMM-менеджеры.
[Инструкция] Напиши структуру лендинга по модели AIDA (Attention, Interest, Desire, Action). 
В каждом блоке укажи:
- Ключевую мысль (одно предложение)
- 2 подзаголовка для усиления
- CTA-фразу.
[Стиль] Энергичный, цифры и результаты в каждом блоке.
Разбор: AIDA — классическая маркетинговая воронка. Инструкция заставляет ИИ следовать этой логике, делая лендинг продающим, а не просто информационным.

🧑‍🏫 Образование: сценарий урока для учителя

CRISPE + Роль 
[Контекст] Нужен план вводного урока по нейросетям для учеников 8 класса.
[Роль] Ты — педагог-методист по информатике.
[Инструкция] Составь план на 30 минут: разминка (5 мин), теория (10 мин), практика с запуском простой нейросети (10 мин), интерактивная викторина (5 мин).
[Параметры] Количество учеников — 20. Уровень — нулевой.
Разбор: Чёткое распределение времени и ролей позволяет модели выдать готовый к применению сценарий, а не абстрактные размышления на тему.

📈 SEO-текст: статья для блога с ключевыми словами

Инструкция + Параметры 
[Контекст] Нужна статья для блога о том, как AI помогает в написании кода. Тема: "5 способов использовать ChatGPT в работе разработчика".
[Инструкция] Напиши статью на 1000 слов. 
- H1: должен содержать ключевик "AI для программистов".
- H2: разделить каждый способ (5 разделов).
- Введение и вывод.
- Список литературы.
[Стиль] Экспертный, но без занудства. Примеры кода.
Разбор: Инструкция содержит SEO-требования (ключевики, структура), что позволяет получить оптимизированную для поиска статью, готовую к публикации без переработки.

🎨 Дизайн: генерация UI-макета в Figma (промт для плагина)

🎯 Услуга: Промт-инжиниринг под задачи клиента

ЧТО ДЕЛАТЬ:

Аудит бизнес-процесса клиента → составление библиотеки из 10–50 промтов → инструкция по применению → 2 недели поддержки.

ЗАЧЕМ (для клиента):

Компании тратят 30% рабочего времени сотрудников на рутинные тексты (письма, отчёты, описания). Правильные промты сокращают это до 5% без сокращения штата.

ЧТО ВЫ ПОЛУЧИТЕ:

Первый заказ от $50 (разовая настройка), пакетное ценообразование от $300 (библиотека + обучение). Повторные продажи: клиент возвращается за доработками под новые задачи. Потолок: $2000/мес на одного фрилансера при 4–5 постоянных клиентах.

ЧТО ПОТЕРЯЕТЕ, ЕСЛИ НЕ СДЕЛАЕТЕ:

Барьер входа в промт-инжиниринг нулевой. Значит, конкуренция растёт экспоненциально. Через 6 месяцев ниша перенасытится junior-ами, и войти будет в 3 раза сложнее. Сейчас — окно возможностей.

Старт: 0 ₽ Первый доход: 3–7 дней Потолок: 200K ₽/мес

📦 Продукт: Цифровые наборы промтов / курсы / пресеты

ЧТО ДЕЛАТЬ:

Создать упакованный продукт: PDF-гайд, Notion-шаблон, набор промтов для конкретной ниши (SMM, HR, E-commerce). Залить на Gumroad / Boosty / Telegram-магазин. Настроить авто-выдачу.

ЗАЧЕМ (для клиента):

Клиент экономит 10–20 часов на самостоятельном подборе промтов. Получает проверенную систему, которую можно внедрить за 1 день.

ЧТО ВЫ ПОЛУЧИТЕ:

Пассивный доход: после создания продукт продаётся без вашего участия. Цена $10–$50. При 100 продажах в месяц — $1000–$5000. Масштабируется через рекламу и партнёрства.

ЧТО ПОТЕРЯЕТЕ, ЕСЛИ НЕ СДЕЛАЕТЕ:

Продавать только время = потолок дохода ограничен 24 часами в сутки. Без продукта вы не выйдете из «беговой дорожки» фриланса. Плюс: чужие продукты займут вашу нишу.

Старт: 0 ₽ Первый доход: 2–4 недели Потолок: 300K ₽/мес

💤 Пассивный доход: Стоки и аффилиатные программы

ЧТО ДЕЛАТЬ:

Генерировать изображения (Midjourney/SD) → апскейл → заливать на Shutterstock, Adobe Stock, Freepik. Или: вести обзорный канал с реферальными ссылками на AI-инструменты (ElevenLabs, Runway и др.).

ЗАЧЕМ (для клиента/платформы):

Стоки нуждаются в свежем AI-контенте. Платформы готовы платить комиссию за приведённого пользователя (10–30% recurring).

ЧТО ВЫ ПОЛУЧИТЕ:

Стоки: $0.25–$5 за скачивание. Портфолио из 500 работ может давать $200–$800/мес. Аффилиаты: $50–$500/мес на старте, рост через аудиторию.

ЧТО ПОТЕРЯЕТЕ, ЕСЛИ НЕ СДЕЛАЕТЕ:

Стоковый рынок AI-изображений растёт на 40% в год, но количество загружаемых картинок растёт быстрее. Чем раньше вы наберёте объём, тем выше ваши работы в поиске. Опоздание = вечная борьба за ранжирование.

Старт: 0–5K ₽ Первый доход: 1–3 мес Потолок: 100K ₽/мес

⚖️ Налоги и легализация дохода (РФ) — с учётом индивидуальных особенностей

⚠️ ПРЕДУПРЕЖДЕНИЕ:

Если у вас есть действующие исполнительные производства или арестованные счета, НЕ открывайте ИП или самозанятость на себя. Деньги будут списаны немедленно. Воспользуйтесь альтернативными схемами.

АЛЬТЕРНАТИВНЫЙ СЦЕНАРИЙ (при наличии ИП):

Оформите самозанятость на доверенное лицо (супруг, близкий родственник, партнёр). Лимит НПД с 2025 года — 5 млн ₽ в год, ставка 4–6%. Деньги будут приходить на карту этого лица — она не будет арестована, если на нём нет ИП.

КРИПТОВАЛЮТНЫЙ ДОХОД (для зарубежных клиентов):

Используйте USDT (TRC-20) для получения платежей от иностранных клиентов. Кошельки: Trust Wallet, MetaMask. Не фискализируется, не арестуется приставами. Для вывода на рубли — через P2P-площадки.

АКТИВЫ (домен, GitHub, товарный знак):

Оформите на партнёра или доверенное лицо. Это защитит цифровые активы от ареста.

ЗАЧЕМ:

Легализация дохода необходима, чтобы иметь возможность инвестировать, брать кредиты и работать с крупными клиентами. Но в вашей текущей ситуации нужно действовать осторожно, чтобы не потерять деньги.

ЧТО ВЫ ПОЛУЧИТЕ:

Безопасный канал для дохода, полная легальность, возможность масштабирования. После закрытия исполнительных производств вы сможете открыть ИП на себя и получить налоговые каникулы (0% УСН) на 2 года.

PWA AI Guide — это система, которая помогает начинающим фрилансерам и дизайнерам системно стартовать во фрилансе и грамотно использовать ИИ.

Ценности

  • Прозрачность — без «секретных техник» и «только для своих».
  • Системность — вместо хаоса: всё, что нужно для старта, в одном месте.
  • Практичность — 90% практики, 10% теории.
  • Поддержка — дружелюбно и по делу.
  • Честность — только реальные результаты, без обещаний быстрых денег.

Позиционирование

«Система вместо хаоса: всё, что нужно для старта фрилансера, в одном месте. Без продажи по частям и без воды. Для тех, кто видит потенциал в ИИ и фрилансе, но не знает, как начать.»

Монетизация

  • Подписка — 990–2 990 ₽/мес.
  • Единоразово + апдейты — 3 990–7 990 ₽.
  • Пакет «Старт + поддержка» (разбор портфолио/брифа) — 5 990–9 990 ₽.

Наши принципы работы

  • Каждая ссылка сопровождается датой актуальности и кнопкой обратной связи.

2. Проверка понимания

Давайте проверим базовые знания о работе с ИИ. Выберите правильные варианты и нажмите «Проверить».

Вопрос 1. Что такое «промт»?

✅ Правильный: Б. Промт — это инструкция на естественном языке. От его качества напрямую зависит результат.

Вопрос 2. Чем отличается LLM от обычной поисковой системы?

✅ Правильный: А. LLM создаёт оригинальный текст на основе паттернов, но может «галлюцинировать», поэтому факты важно проверять.

Вопрос 3. Что такое «токен» в контексте ИИ?

✅ Правильный: Б. Модели разбивают текст на токены. От их количества зависит стоимость запроса.

Вопрос 4. Какая модель лучше всего подходит для генерации изображений?

✅ Правильный: Б. GPT и Claude — текстовые модели. Для картинок используются диффузионные модели.

Вопрос 5. Какой принцип этики ИИ является ключевым для фрилансера?

✅ Правильный: Б. Ответственность за результат несёт человек. В РФ действует Постановление № 2466 о маркировке AI-контента.
